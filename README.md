## 产品怎么走

```text
这间空房 → 过走道和面宽 → 能买的货单 → 确认后再画进这间房
```

1. **看这间房** — 照片认地板墙光，不当尺子。厘米由用户确认。
2. **先出货单** — 宜家成品，带货号和链接。目录里没有的不会画。
3. **硬门** — 两侧 20cm、进深不超过房间 45%、走道 80cm。过不了的沙发不会出现。
4. **再合成** — 只把已经锁定的货摆进照片。效果图不是实测。

语言模型听懂口味，听不懂这间房过不过。过不过由确定性代码决定。
